Cloud & Security Architecture Portfolio

Demonstrating Secure Data Transmission & Global Distribution Networks

Project Overview

This documentation site is hosted on highly available cloud storage and delivered globally via an edge-cached Content Delivery Network (CDN) enforcing strict HTTPS.

Security Paradigms Implemented

  • Data at Rest: Cryptographic file segmentation with individualized AES-256-GCM block encryption.
  • Data in Transit: Forced TLS/HTTPS redirection utilizing Edge-Node termination rules.
  • Access Control: Isolated backend origin storage using secure Origin Access Control (OAC).
